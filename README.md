# How can I ensure that my code, program, or software is functional and secure?

You ensure your software is functional by testing for what requirements, limits are asked utilizing JUNIT techniques, and securing by testing input validations, authenticating and authorizing and incorporate secure coding practices.

# How do I interpret user needs and incorporate them into a program?

Needing to understand the user's goals by translating them into functional requirements, design classes and methods around those requirements followed by incorporating JUNITS tests to enforce the requirements.

# How do I approach designing software?

Initially understanding the problem of what the system must do. Ensure your design is aligned with the requirements. Next to model the data, define the entities such as:  Contact → id, firstName, lastName, phone, address. Design the behavior including services, methods and rules. Design tests for what invalid inputs should be rejected, incorporating boundaries and success cases. Now we write the code, validate with testing and make corrections accordingly.
